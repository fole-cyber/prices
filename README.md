# בוט מחירים – כפר חב"ד

הבוט אוסף מחירים ומבצעים ובונה את הקובץ `data/catalog-kfar-chabad.json`.
האפליקציה שלך קוראת את הקובץ הזה. הוא מתעדכן לבד:

| חנות | תדירות |
|---|---|
| אושר עד – לוד (020), קריית אונו (032) | 3 פעמים ביום |
| יש חסד – בארות יצחק (300) | 3 פעמים ביום (הקובץ שלהם מתעדכן פעם ביום) |
| ליפסקר, שוליק | פעם בשבוע, ביום רביעי בבוקר |

## התקנה חד-פעמית (כ-10 דקות, בלי ידע בתכנות)

1. נכנסים ל-github.com ופותחים חשבון חינמי.
2. לוחצים על **+** למעלה ← **New repository**. שם: `prices`. בוחרים **Public** ← **Create repository**.
3. בדף שנפתח לוחצים **uploading an existing file** וגוררים לחלון את **כל התוכן של התיקייה** (כולל התיקייה `.github`). לוחצים **Commit changes**.
   - אם התיקייה `.github` לא עלתה (היא מוסתרת לפעמים): **Add file ← Create new file**, בשם כותבים `.github/workflows/update-prices.yml`, ומדביקים את תוכן הקובץ.
4. לשונית **Actions** ← אם מופיעה בקשה להפעיל, לוחצים אישור.
5. בלשונית **Actions** בוחרים **עדכון מחירים** ← **Run workflow**. אחרי 2–3 דקות יופיע וי ירוק, והקובץ ייווצר בתיקייה `data`.

## שינוי רשימת הקניות
עורכים את `shopping_list.txt` ישירות באתר (סמל העיפרון). מילה או שתיים בכל שורה.

## מבנה הקובץ
```json
{"collected":"2026-11-07","updated_at":"...","stores":{"osherad_lod":{"updated":"..."}},
 "products":[{"barcode":"...","name":"...","unit":"250 גרם","category":"קוטג",
   "prices":{"osherad_lod":{"price":6.5,"deal":{"price":6,"terms":"2 ב-12","min_qty":2,"until":"2026-11-20"}},
             "lipsker":{"price":6.6,"deal":null,"match":{"by":"name","score":0.81}}}}]}
```
- `deal.price` – מחיר ליחידה במבצע. המבצע תקף רק כשקונים לפחות `min_qty` יחידות.
- `club_only: true` – מבצע לחברי מועדון בלבד.
- `match.review: true` – ההתאמה לפי שם פחות בטוחה. כדאי לבדוק.
- `stores.*.updated` – מתי כל חנות עודכנה. אם עברו יותר מכמה ימים, כדאי להציג אזהרה באפליקציה.
